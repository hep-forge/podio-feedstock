# podio-feedstock

[![Build AMD64](https://github.com/hep-forge/podio-feedstock/actions/workflows/autoupload.amd64.yml/badge.svg)](https://github.com/hep-forge/podio-feedstock/actions/workflows/autoupload.amd64.yml)
[![Build ARM64](https://github.com/hep-forge/podio-feedstock/actions/workflows/autoupload.arm64.yml/badge.svg)](https://github.com/hep-forge/podio-feedstock/actions/workflows/autoupload.arm64.yml)

Feedstock for [podio](https://github.com/AIDASoft/podio) — part of [hep-forge](https://anaconda.org/hep-forge).

PODIO is a C++ library to support the creation and handling of data models in particle physics.

## Install

```bash
conda install -c hep-forge -c conda-forge podio
```
